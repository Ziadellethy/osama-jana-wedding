# Osama & Jana — Wedding Invitation

موقع دعوة فرح أسامة وچنا (صفحة واحدة: `index.html`، مفيش حاجة تتثبّت).

## النشر
- **GitHub Pages:** Settings ← Pages ← Branch: `main` / root.
- **Netlify / Vercel:** اربط الريبو، من غير Build command، والـ publish directory هو الجذر `/`.

## التعديل
كل البيانات (الأسماء، التاريخ، الوقت، العنوان، لينك الخريطة، Supabase) في كتلة `CONFIG` أول السكريبت داخل `index.html`.
